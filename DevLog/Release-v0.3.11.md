So it's been nearly a month since the last version release of Crack Tunes and a lot has happened. The main big change is that since the bot got verified by discord, the message content intents have been removed and Crack Tunes *no longer can support prefix commands*. I know that many people prefer them, so one of my top priorities going forward in the next couple of weeks will be to implement a feature or features which will justify the need for message content intents and then I can again support prefix commands. In the mean time enjoy the increased stability and performance that Crack Tunes now has after several weeks of debugging and code fixes.

tldr:
- No more prefix commands.
- Stability and performance improvements.
- Admin command to mute all others in a vc.
- New features in the works
